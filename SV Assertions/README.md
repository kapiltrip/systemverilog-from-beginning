# SystemVerilog Assertions

> An ordered practice track for SystemVerilog Assertions (SVA).

[All learning tracks](../README.md)

This track is ready for the assertion code written in EDA Playground. Each new playground will be captured in order with its source, saved browser link, answers to questions written in the code, observed output or errors, and any supporting screenshots.

## Start here

1. Read [Foundation 00 — Event Scheduling Regions and Assertion Types](Foundations/00-event-scheduling-regions-and-assertion-types/README.md) to understand sampling, evaluation, pass/fail scheduling, immediate assertion types, and all 17 event regions.
2. Open the [ordered assertion lesson index](Codes/README.md). No assertion playground has been captured yet, so numbering will begin with Part 01 when the first browser-written lesson is ready.

The foundation note is deliberately outside `Codes/`: it contains source-checked explanations and illustrative examples, while `Codes/` remains reserved for the ordered EDA Playground captures.
