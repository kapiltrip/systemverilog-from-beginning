# SystemVerilog Learning Tracks

This repository is organized by topic. Open a track below to reach its ordered lessons, source code, explanations, screenshots, and saved EDA Playground links.

| Track | Current contents |
|---|---|
| [SV Basics](SV%20Basics/README.md) | Parts 01–44, covering language fundamentals through a layered monitor-and-scoreboard testbench. |
| [SV Assertions](SV%20Assertions/README.md) | Foundation 00 explains event regions and assertion types; the ordered browser-playground sequence is ready to begin at Part 01. |

## How this grows

New browser-written basics playgrounds continue inside `SV Basics` in the same numbered order. Assertion playgrounds go inside `SV Assertions`. When another major topic begins, it can be added here as a separate top-level track without mixing its lessons into the existing sequences.
