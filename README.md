## Repository convention

- `testbench.sv` contains the original EDA Playground testbench.
- `design.sv` mirrors the design pane from EDA Playground.
- The part-level `README.md` explains the example and answers its questions.
- The numeric folder prefixes are the authoritative learning sequence.
